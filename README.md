# FinControl

## Sobre o projeto

Este projeto foi desenvolvido para a disciplina de Programação Mobile Coding.

O FinControl é um aplicativo de controle financeiro pessoal que ajuda o usuário a acompanhar seus gastos e receitas de forma simples e organizada.

## Funcionalidades

* Tela de login
* Tela inicial com saldo financeiro
* Visualização de receitas e despesas
* Tela de perfil
* Tela de configurações
* Logout do sistema

## Tecnologias utilizadas

* React Native
* JavaScript
* Expo Snack

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o projeto:

```bash
npx expo start
```

3. Abra o aplicativo usando o Expo Go ou um emulador.

## Objetivo

O objetivo deste aplicativo é ajudar pessoas que têm dificuldade em controlar seus gastos mensais, permitindo acompanhar entradas, saídas e o saldo disponível.
